# 🐍 Snake Game

A classic Snake game built with TypeScript, Vite, and Canvas API.

## Features

- 🎮 Classic Snake gameplay
- ⌨️ Keyboard controls (Arrow Keys or WASD)
- ⏸️ Pause/Resume functionality
- 📊 Real-time score tracking
- 🚀 Increasing difficulty as you progress
- 📱 Responsive design

## How to Play

1. Use Arrow Keys or WASD to move the snake
2. Eat the red food to grow and earn points
3. Don't crash into yourself or the walls (they wrap around)
4. Press Space or click "Pause" to pause/resume
5. Click "Reset" to start a new game

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production (outputs static files to dist/)
npm run build

# Preview production build
npm run preview
```

## Technology Stack

- **TypeScript**: Type-safe JavaScript
- **Vite**: Fast build tool and dev server
- **Canvas API**: Game rendering
- **HTML5**: Semantic markup
